# Помощник по расписанию

Фраза «завтра в три консультация» превращается в событие с напоминанием.

## Сборка
1. Android Studio Koala (2024.1.1) или новее. **Gradle JDK — 17 или 21** (Settings → Build Tools → Gradle); JDK 25 не поддерживается этой версией Gradle.
2. File → Open → папка проекта, дождаться Gradle Sync.
3. Run ▶ на устройстве/эмуляторе (minSdk 26, targetSdk 34).
4. Тесты: `./gradlew test`

## Что сделано
- F1: разбор фразы → карточка с подтверждением и правкой
- F2: повестка «День / Неделя», редактирование, удаление, напоминание за 15 минут
- T3: события хранятся как момент (UTC) + zoneId; после смены пояса момент не меняется, исходное время показывается в карточке; напоминания и виджет перерегистрируются после перезагрузки, перевода часов и смены пояса
- T2: запись событий в системный календарь (Calendar Provider) и чтение оттуда, обработка разрешений READ/WRITE_CALENDAR; тесты парсера
- T1: виджет на Glance — ближайшие события, обновление при изменении данных и в полночь, открытие события по нажатию
- F3: предупреждение о пересечении, поиск, ручная форма для неразобранных фраз

## Дизайн
Фирменная тема (индиго → фиолетовый), светлая и тёмная схемы, векторные иконки в `res/drawable`, адаптивная иконка приложения (`res/mipmap-anydpi-v26`), исходник логотипа — `design/logo.svg`.

## Архитектура
ui (Compose) → EventViewModel → domain (ScheduleParser, ConflictChecker) / data (Room) / reminder (AlarmManager)

## Известные ограничения
- Числовые даты («25.10») не разбираются.
