# Помощник по расписанию

Фраза «завтра в три консультация» превращается в событие с напоминанием.

## Сборка
1. Android Studio Koala (2024.1.1) или новее, JDK 17.
2. File → Open → папка проекта, дождаться Gradle Sync.
3. Run ▶ на устройстве/эмуляторе (minSdk 26, targetSdk 34).
4. Тесты: `./gradlew test`

## Что сделано
- F1: разбор фразы → карточка с подтверждением и правкой
- F2: повестка «День / Неделя», редактирование, удаление, напоминание за 15 минут
- F3: предупреждение о пересечении, поиск, ручная форма для неразобранных фраз

## Архитектура
ui (Compose) → EventViewModel → domain (ScheduleParser, ConflictChecker) / data (Room) / reminder (AlarmManager)

## Известные ограничения
- Ещё нет виджета, системного календаря, повторной регистрации напоминаний после перезагрузки (T1–T3).
- Числовые даты («25.10») не разбираются.
